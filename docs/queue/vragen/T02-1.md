# T02-1: dispersie in Mitsuba

**Vraag:** Mag plan §2 punt 1 (n met dispersie) worden aangepast naar "vaste IOR bij 589,3 nm" als gedocumenteerde beperking?

**Waarom nu:** Mitsuba 3.9.1 `dielectric` accepteert alleen een scalaire `int_ior` (float of materiaalnaam). Getest: een
spectrum geeft "wrong type (expected string, got spectrum)". Er is geen dispersief BSDF-plugin. Out-of-the-box is
dispersie dus niet mogelijk; de Cauchy-coefficienten staan wel in `EpoxyMaterial` en de scene gebruikt n(589,3 nm) = 1,530.

**Opties:**
1. Vaste IOR (nu gedaan), beperking noteren in plan §2. Effect van dispersie op een 2-6 cm blok is klein (n 1,54 bij 400 nm vs 1,52 bij 700 nm).
2. Eigen BSDF-plugin in C++ met golflengte-afhankelijke IOR (veel werk, eigen build).
3. Per golflengteband meerdere renders met een eigen IOR en samenvoegen (onnauwkeurig, duur).

**Aanbevolen:** optie 1; optie 3 alleen als later blijkt dat kleurzomen ertoe doen.
