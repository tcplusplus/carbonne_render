# T23 — Cloudflare-tunnel

## Doel
De MCP-server bereikbaar maken voor een chatassistent in de cloud, **zonder poorten open te zetten** in de
router. Gekozen door de gebruiker: een Cloudflare Tunnel met een gratis adres, zonder eigen domein.

## Scope
- `cloudflared` installeren. **Vraag dat vooraf via de orkestrator**: een systeempakket of een losse binary in
  `~/.local/bin`, met de aanbeveling erbij.
- `carbonne-tunnel` (of een script):
  - start de MCP-server als die nog niet draait, en start `cloudflared tunnel --url http://127.0.0.1:8001`
    (een quick tunnel op trycloudflare.com);
  - leest de publieke URL uit en print de volledige connector-URL, met het pad en het token zoals T22 ze
    vastlegt;
  - stopt allebei netjes bij Ctrl-C.
- Een quick tunnel krijgt **bij elke start een nieuw adres**. Documenteer dat de connector dan opnieuw ingesteld
  moet worden, en beschrijf als alternatief een benoemde tunnel met een gratis Cloudflare-account (vast adres
  zonder eigen domein, als dat nog bestaat; zoek het na).
- Alleen de MCP-server gaat door de tunnel, **niet** de volledige webapp.
- Werk `docs/chat-koppeling.md` bij.

## Bewijs
Een curl via de publieke URL zonder token (geweigerd) en met token (de lijst met tools). Claude Code als MCP-client
via de publieke URL: één tool-aanroep (`verven_lijst`).
