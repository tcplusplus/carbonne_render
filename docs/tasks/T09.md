# T09 — Webbackend

## Scope
- FastAPI-app in `carbonne.server`, gestart met `carbonne-app` (uvicorn, alleen 127.0.0.1, poort 8000). Ze serveert
  ook de statische bestanden uit `web/`.
- Endpoints:
  - `GET /api/schema`: het JSON-schema van de config; `GET /api/presets`: omgevingen, camera's, RAL-lijst.
  - `GET /api/hdri/{naam}`: een kleine (1k) versie van de HDRI voor de preview (genereer ze één keer en cache ze).
  - `POST /api/render` → job-id; `WS /api/render/{id}`: voortgang en tussenbeelden; `DELETE` annuleert.
  - `GET /api/render/{id}/result.png|.exr`.
  - `GET/POST /api/configs`: benoemde configs opslaan als JSON in `configs/`.
- **Eén render tegelijk** (één GPU), met een wachtrij. Een nieuwe render met dezelfde hash komt uit de cache.
- Rendert in een aparte thread of een apart proces, zodat de server responsief blijft.

## Bewijs
API-tests met `httpx`/`TestClient`, met een renderer die in tests een nep-backend kan gebruiken (snel). Eén echte
end-to-end-render op lage resolutie.
