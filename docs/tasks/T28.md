# T28 — Frontend naar TypeScript

## Aanleiding
De gebruiker verwacht dat de frontend blijft groeien en wil de typecontrole van Pydantic ook aan de
frontendkant (de 422-meldingen bij inhoud). Besluit van de gebruiker: **TypeScript, geen Vue**.

## Scope
- Vite + TypeScript, geen framework. De modules uit `web/js/` worden `.ts` (strikte `tsconfig`); de structuur en de
  naamgeving blijven; **geen herontwerp** van de UI.
- Types: genereer `web/src/types/config.ts` uit `GET /api/schema` (bijvoorbeeld `json-schema-to-typescript`) met
  een script (`npm run types`) dat ook in de test draait, zodat de types niet achterlopen op `core/config.py`.
  Combineer met de schema-gedreven limieten en validatie uit T27.
- three.js uit npm in plaats van `web/vendor/`; de app blijft werken zonder internet.
- Build: `npm run build` schrijft `web/dist/`. **`web/dist/` staat in git**, zodat starten alleen
  `uv run carbonne-app start` vraagt. De backend serveert `web/dist/`.
- `npm run dev` voor ontwikkelen met herladen (optioneel); documenteer alles in `docs/gebruik.md`.
- Vraag de gebruiker eerst bevestiging voor het installeren van npm-pakketten buiten wat Vite/TypeScript/
  three.js/json-schema-to-typescript vraagt.

## Bewijs
`tsc --noEmit` schoon; een test dat een verkeerd type (bv. `count: "veel"`) niet compileert; de
Playwright-tests uit T10, T16, T20 en T27 blijven groen tegen `web/dist/`.
