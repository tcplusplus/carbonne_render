# T22 — MCP-server

## Doel
Een chatassistent (ChatGPT met een abonnement dat eigen connectors toelaat, of Claude) laat in gewone taal verven
opzoeken en vertalen, tafeltjes instellen en renderen. Haar ChatGPT is nu Free: deze server moet **klaarstaan**
voor later, en wordt nu getest met Claude Code als client.

## Scope
- `carbonne.mcp` met de officiële Python MCP-SDK (`mcp`), transport **Streamable HTTP**. Draait als eigen proces
  `carbonne-mcp` (poort 8001) en spreekt intern de functies van de kern en de server aan, **zonder** logica te
  dupliceren.
- **Tools.** Elke tool heeft een duidelijke beschrijving, want die beschrijving is de handleiding voor het LLM.
  - `verf_schema` en `verf_vertalen(eigenschappen)`. De beschrijving zegt: zoek eerst het technische fiche,
    geef de glans als GU bij 60° als die er staat, gok geen hex maar zeg wat onzeker is, en meld de
    waarschuwingen aan de gebruiker.
  - `verf_opslaan`, `verven_lijst`, `verf_ophalen`.
  - `tafel_opties`: diameters, diktes, afwerkingen, omgevingen, camera's en bibliotheekverven, compact.
  - `tafel_valideren(config)`: geeft de genormaliseerde config of een leesbare fout.
  - `render_starten(config, kwaliteit="preview"|"hq", herkomst=False)` → job-id; `render_status(job_id)` → de
    voortgang en, als hij klaar is, een **afbeeldings-URL** plus het beeld als MCP-image-content (klein).
  - `herkomst(job_id, x, y)` en `wat_als_starten`/`wat_als_status`, op basis van T15.
- **Lange jobs**: geen tool wacht langer dan ongeveer 20 s. De beschrijvingen zeggen dat het LLM de status
  later opnieuw moet opvragen.
- **Beveiliging**: een bearer-token of geheim pad, en een fout zonder token. Zoek uit welke authenticatie
  ChatGPT- en Claude-connectors nu verwachten (OAuth, of geen authenticatie met een geheime URL) en documenteer
  het. Moet er OAuth komen, parkeer dan eerst een vraag met de opties.
- `docs/chat-koppeling.md`: hoe je de connector toevoegt in Claude en in ChatGPT, welk abonnement dat vraagt
  (met datum en bron, want dat verandert), en voorbeeldvragen.

## Bewijs
- Unittests per tool (met de nep-renderer).
- End-to-end: Claude Code verbindt met `http://127.0.0.1:8001/mcp` (`claude mcp add --transport http ...`) en
  voert het scenario uit de zichtbare stap uit. Bewaar het transcript in de evidence.
