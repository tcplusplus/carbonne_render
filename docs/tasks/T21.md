# T21 — Webapp in het thuisnetwerk

## Doel
De vrouw van de gebruiker opent de app vanaf haar eigen toestel op hetzelfde wifi: `http://<laptop>:8000`.

## Scope
- `carbonne-app --lan`: bindt op `0.0.0.0` en print de bruikbare adressen (het LAN-IP en, als het werkt,
  `<hostnaam>.local`). Zonder de vlag verandert er niets (alleen `127.0.0.1`).
- Een eenvoudige **toegangscode** in LAN-modus, zodat niet elk toestel in het netwerk renders kan starten. De
  code wordt bij de eerste start gegenereerd en bewaard in `~/.config/carbonne/`, en geprint als link met de
  code erin (één keer openen zet een cookie). Lokaal (`127.0.0.1`) is geen code nodig.
- Controleer of er een firewall (ufw) actief is. Als dat zo is: **wijzig hem niet zelf**, maar documenteer het
  commando en vraag de gebruiker via de orkestrator.
- `docs/gebruik.md`: een sectie "Vanaf een ander toestel".

## Bewijs
Tests van de toegangscode (zonder code 401, met code of cookie 200, lokaal altijd 200). Een curl vanaf het
LAN-IP van de laptop zelf.
